# BDO UA Client — зображення для вебгайдів

Окремий набір актуальних скріншотів клієнта для використання у вебпроєкті та майбутніх гайдах. Зображення збережені без змін.

| Файл | Стан |
|---|---|
| `bdo-ua-client-not-installed.png` | Локалізацію ще не встановлено |
| `bdo-ua-client-installed.png` | Локалізацію встановлено |
| `bdo-ua-client-update-available.png` | Для встановленого режиму доступне оновлення |

Ці файли є довідковими матеріалами для вебгайдів і не є runtime-ресурсами застосунку.
