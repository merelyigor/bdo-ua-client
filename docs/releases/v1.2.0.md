# BDO UA Client 1.2.0

Стабільний реліз із підтримкою системного трея та фонового контролю оновлень локалізації.

Версія: `1.2.0`
Тег: `v1.2.0`
Commit: `d52fe75a30928a6fd56226676cdfd993c4cb9458`

## Що нового

- BDO UA Client може залишатися запущеним у системному треї Windows.
- Натискання X ховає клієнт у трей, а не завершує його.
- Меню трея містить `Відкрити`, `Перевірити зараз`, `Запускати разом із Windows` і `Вихід`.
- Подвійний клік по іконці трея відновлює клієнт; повторний запуск активує вже існуючий екземпляр.
- Необов'язковий автозапуск Windows запускає клієнт тихо у фоновому режимі.
- У прихованому режимі API перевіряється з меншою частотою, а зміни файлу локалізації виявляються окремим дешевим моніторингом.
- Коли доступне оновлення локалізації, Windows може показати інформаційне сповіщення; повторні сповіщення для тієї самої події пригнічуються.

## Безпека та поведінка

- Локалізація ніколи не встановлюється та не оновлюється непомітно для користувача.
- Приховування вікна не перериває активну операцію локалізації.
- Явний `Вихід` залишається повним завершенням застосунку з чинною безпечною семантикою операцій.

## Технічні зміни

- Внутрішній код MainForm розділено на зрозуміліші partial-області.
- Спільні шляхи локалізації та source markers централізовано.
- API локалізації та схема збереженого стану не змінювалися.

## Відоме обмеження

Сповіщення про оновлення Windows є інформаційним. Клік по ньому не є підтримуваним способом відкрити застосунок. Використовуйте tray `Відкрити`, подвійний клік по іконці трея або звичайний запуск BDO UA Client.

## Як встановити

1. Завантажте `BDO-UA-Client-v1.2.0-win-x64.zip` зі сторінки [GitHub Releases](https://github.com/merelyigor/bdo-ua-client/releases).

4. Якщо Windows SmartScreen покаже попередження — натисніть «Докладніше» → «Виконати» (деталі: [README](https://github.com/merelyigor/bdo-ua-client#windows-smartscreen)).
