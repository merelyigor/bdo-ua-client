Стабільний maintenance-реліз із зрозумілою інструкцією видалення portable-клієнта без плутанини з відновленням локалізації гри.

## Що нового

- У клієнті доступна підказка `Як видалити клієнт?` з поясненням вимкнення автозапуску, повного виходу через трей `Вихід` і видалення `BDO-UA-Client.exe`.
- Пояснено необов’язкове очищення локальних даних у `%LocalAppData%\BDO-UA-Client`.
- Чітко розділено видалення клієнта та повернення оригінальної локалізації гри через дію `Відновити оригінал`.

## Як встановити

1. Завантажте `BDO-UA-Client-v1.2.3-win-x64.zip` зі сторінки [GitHub Releases](https://github.com/merelyigor/bdo-ua-client/releases).
2. Розпакуйте з архіву `BDO-UA-Client.exe`.
3. Запустіть `BDO-UA-Client.exe`.
4. Якщо Windows SmartScreen покаже попередження — натисніть «Докладніше» → «Виконати» (деталі: [README](https://github.com/merelyigor/bdo-ua-client#windows-smartscreen)).
