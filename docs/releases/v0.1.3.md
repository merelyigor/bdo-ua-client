# BDO UA Client 0.1.3

Виправлення попереджень компілятора та покращення якості коду.

Версія: 0.1.3
Тег: v0.1.3
Commit: (заповниться після RC)

## Що нового

- Автоматичний пошук гри (Registry, Steam library, ручний вибір)
- Отримання доступних режимів локалізації через API bdo-ua.com.ua
- Встановлення локалізації з автоматичною перевіркою SHA-256
- Оновлення встановленої локалізації на новішу версію
- Відновлення оригінального файлу гри (Restore Original)
- Автоматичне оновлення списку режимів без перезапуску (live refresh кожні 15 сек)
- Автоматичне визначення наступної версії релізу (auto-increment patch)
- Захист від встановлення несумісних релізів (`compatible_with_official_patch`)
- Діагностика мережевих помилок (TLS, timeout, HTTP)
- Автоматичне видалення логів старше 15 днів

## Виправлено

- Видалено невикористовуване поле `_operationFinalizing` — попередження компілятора
- Виправлено nullable reference попередження в тестах координатора стрічки
- Коректне відображення стану встановленої локалізації після зміни режиму
- Збереження вибраного режиму при оновленні списку через live refresh

## Зміни

- 404 автоматизованих тестів + 13 сценаріїв резолвера версій
- 0 попереджень компілятора
- Діагностичне логування часу відповіді API (headers, body, parse, total)
- Логування часу завантаження файлів локалізації (throughput, correlation headers)
- Семантичне виявлення змін у стрічці релізів (порядок режимів, версії, сумісність)
- Архітектура: FeedApplicationCoordinator для оркестрації оновлень стрічки

## Завантаження

`BDO-UA-Client-v0.1.3-win-x64.zip`

## Як встановити

1. Завантажте `BDO-UA-Client-v0.1.3-win-x64.zip` з цієї сторінки
2. Розпакуйте архів
3. Запустіть `BDO-UA-Client.exe`
4. Якщо Windows SmartScreen покаже попередження — натисніть "Докладніше" → "Виконати" (деталі: [README](https://github.com/merelyigor/bdo-ua-client#windows-smartscreen))

## Відомі проблеми / обмеження

- Інтермітентна затримка при зверненні до API bdo-ua.com.ua (діагностується, пов'язано з мережевим шляхом)
- Backend HTTP cache TTL ~300 сек — нові релізи можуть з'являтися з затримкою до 5 хвилин після публікації
