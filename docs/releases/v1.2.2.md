## Що нового

- Клієнт приблизно кожні 5 хвилин перевіряє наявність новішої версії, навіть коли продовжує працювати у треї.
- Якщо нову версію вперше знайдено у прихованому режимі, Windows показує одне інформаційне сповіщення для цієї версії; після відкриття доступна звичайна кнопка оновлення.
- Tray `Перевірити зараз` перевіряє і доступність локалізації, і версію BDO UA Client.

## Як встановити

1. Завантажте `BDO-UA-Client-v1.2.2-win-x64.zip` зі сторінки [GitHub Releases](https://github.com/merelyigor/bdo-ua-client/releases).
2. Розпакуйте з архіву `BDO-UA-Client.exe`.
3. Запустіть `BDO-UA-Client.exe`.
4. Якщо Windows SmartScreen покаже попередження — натисніть «Докладніше» → «Виконати» (деталі: [README](https://github.com/merelyigor/bdo-ua-client#windows-smartscreen)).
